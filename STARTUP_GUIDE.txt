🔧 OPTION 2: MANUAL STARTUP (STEP-BY-STEP)

Use this if automated scripts don't work or you prefer manual control.

════════════════════════════════════════════════════════════════════
STEP 1: Setup Backend (First Terminal)
════════════════════════════════════════════════════════════════════

1.1) Open Terminal/Command Prompt

1.2) Navigate to backend folder:
     cd DataSentry-AI/backend

1.3) Install dependencies:
     npm install

     ⏱️  Takes: 2-3 minutes
     ✅ Success: "added XXX packages"
     ❌ Error: If fails, delete node_modules folder and try again

1.4) Generate Prisma Client:
     npx prisma generate

     ⏱️  Takes: 10-20 seconds
     ✅ Success: "Generated Prisma Client"
     ❌ Error: Run "npm install @prisma/client" then retry

1.5) Setup Database:
     npx prisma db push

     ⏱️  Takes: 5-10 seconds
     ✅ Success: "Your database is now in sync"
     ❌ Error: Check DATABASE_URL in .env file

     Alternative if above fails:
     npx prisma migrate deploy

1.6) Seed Database with Sample Data:
     npm run prisma:seed

     ⏱️  Takes: 5 seconds
     ✅ Success: "Database seeded successfully"
     ⚠️  Warning: If this fails, you can still run the app
                 (you'll just need to create users manually)

1.7) Start Backend Server:
     npm run start:dev

     ✅ Success: You should see:
        - "Nest application successfully started"
        - "Application is running on: http://[::1]:3001"

     ⚠️  IMPORTANT: Keep this terminal window open!
     ⚠️  Don't close it or the backend will stop!

════════════════════════════════════════════════════════════════════
STEP 2: Setup Frontend (Second Terminal)
════════════════════════════════════════════════════════════════════

2.1) Open NEW Terminal/Command Prompt
     (Keep the first one running!)

2.2) Navigate to frontend folder:
     cd DataSentry-AI/frontend

2.3) Install dependencies:
     npm install

     ⏱️  Takes: 1-2 minutes
     ✅ Success: "added XXX packages"
     ❌ Error: Delete node_modules folder and try again

2.4) Start Frontend Server:
     npm run dev

     ✅ Success: You should see:
        - "VITE vX.X.X  ready in XXX ms"
        - "➜  Local:   http://localhost:3000/"

     ⚠️  IMPORTANT: Keep this terminal window open too!

🐛 TROUBLESHOOTING GUIDE

═══════════════════════════════════════════════════════════════════
Problem: Backend won't start / Port 3001 already in use
═══════════════════════════════════════════════════════════════════

Windows Solution:
  1. Open Command Prompt as Administrator
  2. Run: netstat -ano | findstr :3001
  3. Note the PID number
  4. Run: taskkill /PID [number] /F
  5. Restart backend

Mac/Linux Solution:
  1. Run: lsof -ti:3001
  2. Run: kill -9 [PID from above]
  3. Restart backend

═══════════════════════════════════════════════════════════════════
Problem: Frontend won't start / Port 3000 already in use
═══════════════════════════════════════════════════════════════════

Windows Solution:
  1. Open Command Prompt as Administrator
  2. Run: netstat -ano | findstr :3000
  3. Note the PID number
  4. Run: taskkill /PID [number] /F
  5. Restart frontend

Mac/Linux Solution:
  1. Run: lsof -ti:3000
  2. Run: kill -9 [PID from above]
  3. Restart frontend

═══════════════════════════════════════════════════════════════════
Problem: "Module not found" errors
═══════════════════════════════════════════════════════════════════

Solution:
  1. Delete node_modules folder (in backend OR frontend)
  2. Delete package-lock.json file
  3. Run: npm install
  4. Restart the server

═══════════════════════════════════════════════════════════════════
Problem: Database errors / Prisma errors
═══════════════════════════════════════════════════════════════════

Solution 1 - Reset Database:
  cd backend
  rm -f prisma/dev.db         (Mac/Linux)
  del prisma\dev.db           (Windows)
  npx prisma db push
  npm run prisma:seed

Solution 2 - Regenerate Prisma:
  cd backend
  npx prisma generate
  npx prisma db push

═══════════════════════════════════════════════════════════════════
Problem: Login doesn't work / No users in database
═══════════════════════════════════════════════════════════════════

Solution - Reseed Database:
  cd backend
  npm run prisma:seed

If that fails, manually reset:
  cd backend
  npx prisma migrate reset
  npm run prisma:seed

═══════════════════════════════════════════════════════════════════
Problem: Upload doesn't work
═══════════════════════════════════════════════════════════════════

Solution:
  1. Check backend/uploads folder exists
  2. If not, create it manually
  3. Restart backend server
  4. Try upload again

═══════════════════════════════════════════════════════════════════
Problem: Notifications don't appear
═══════════════════════════════════════════════════════════════════

Solution:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Hard refresh (Ctrl+Shift+R)
  3. Try incognito/private window
  4. Check browser console (F12) for errors

═══════════════════════════════════════════════════════════════════
Problem: Export doesn't work
═══════════════════════════════════════════════════════════════════

Solution:
  1. Check browser download settings
  2. Disable popup blocker for localhost
  3. Try different browser
  4. Check browser console (F12) for errors
